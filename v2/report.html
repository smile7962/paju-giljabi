원본 HWPX 서식

원본 HWPX 양식을 선택하면 선택한 출장장소의 보고서를 HWPX로 저장할 수 있습니다.

선택한 파일은 외부 서버로 전송하지 않습니다. 원본 표·글꼴·결재란을 그대로 사용하며 문서에 필요한 텍스트만 채웁니다. 현장사진은 현재 HWPX에 자동 포함되지 않으므로 온나라에서 별도로 첨부하거나 한글에서 삽입해야 합니다.

보고서는 선택한 장소의 일시·참석·현장 확인내용·조치사항만 반영합니다. AI 문장정리는 아직 미연결입니다.

현장사진 불러오기

이메일로 받은 사진을 선택하세요. 파일명의 출장 ID + 방문지 ID + 계획주소가 일치할 때만 자동분류합니다.

사진을 불러오지 않았습니다.

선택한 장소에 연결된 사진만 이 장소의 사진대지에 들어갑니다. 자료는 현재 PC 브라우저에 저장됩니다.
