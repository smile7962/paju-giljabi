원본 HWPX 서식

원본 HWPX 양식을 선택하면 선택한 출장장소의 보고서를 HWPX로 저장할 수 있습니다.

선택한 파일은 외부 서버로 전송하지 않습니다. 원본 상단의 빨간 기본값(3년·건축신고3팀장)을 공란 처리하고, 표·글꼴·결재란은 유지하며 본문 내용만 채웁니다. 선택한 장소의 JPG·PNG·WEBP 현장사진은 HWPX 뒤쪽에 붙임 페이지로 자동 포함됩니다. HEIC는 JPG로 변환 후 불러오세요. 사진 첨부 후 한글·온나라에서 최종 확인하세요.

위 항목과 출장목적만 원본 HWPX의 본문에 입력됩니다.

문장 초안 · 담당자 확인

현재 메모를 정리해 미리보기로 표시합니다. 승인 전에는 작성내용을 변경하지 않습니다.

AI 연결은 기본적으로 꺼져 있습니다. 기관 승인된 프록시 주소를 입력하고 비민감·합성자료일 때만 사용하세요. 사진은 AI에 전송하지 않습니다.

현장메모를 입력한 다음 초안을 생성하세요.

모바일 출장기록 가져오기

현장사진 불러오기

이메일로 받은 사진을 선택하세요. 파일명의 출장 ID + 방문지 ID + 계획주소가 일치할 때만 자동분류합니다.

사진을 불러오지 않았습니다.

선택한 장소에 연결된 사진만 이 장소의 사진대지에 들어갑니다. 자료는 현재 PC 브라우저에 저장됩니다.
