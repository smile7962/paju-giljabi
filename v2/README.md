# 출장ON AI v0.1 — 기능개발 1단계

이 폴더는 기존 파주길잡이를 기반으로 한 출장ON AI의 **첫 기능 실행판**입니다.

- UI 원본: [Claude 시안](../design/claude-prototype.html)
- 실사용 개발 파일: `index.html`, `style.css`, `app.js`
- 프레임워크·빌드 도구 없음. 브라우저에서 `v2/index.html` 열기.

## 현재 동작
1. 출발·복귀지와 방문지(최대 15곳)를 입력
2. OpenStreetMap Nominatim을 통해 주소 좌표 확인 (1.15초 간격)
3. OSRM 도로망으로 방문순서와 왕복 경로 계산
4. Leaflet 지도에 경로·방문지 표시
5. 총 이동거리·예상 이동시간·방문순서 표시
6. 브라우저 인쇄

**현재 미구현:** Gemini 자연어 분석, 시간예약·우선방문 제약 최적화, QR 인계, 모바일 사진, 복명서. 버튼에서 미구현 상태를 명확히 표시합니다.
